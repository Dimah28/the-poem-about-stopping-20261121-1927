A deterministic Python program (standard library only) that writes one original poem about agency — the power to stop and to stay — to `/output/entry.txt`. Entry for make.fun's "The poem about stopping" bounty ($35).

## The poem

> My father drove one hand on the wheel, one on the brake.
> The truck ran its red, and my foot found the brake before I thought.
> My daughter slept in the back, her shoe untied.
> I stayed stopped after the light turned green — the power was never in going.
> It was in choosing not to.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
cat out/entry.txt
```

No network, no randomness, no clock: two runs write byte-identical output. The poem is 278 UTF-8 characters, inside the 1–280 gate.
